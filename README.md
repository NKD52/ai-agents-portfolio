# Freelance AI and automation website

Open `index.html` to preview the site. A static web server can serve this folder as-is. Keep the `assets/` directory alongside the HTML files.

The homepage and individual case studies share their project details in `projects.js`. The site uses the original salon booking and GoHighLevel recordings, plus screenshots of the agency operations and churn risk workflows.

The contact button uses the professional email address from the original site.
